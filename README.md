# Habit Tracker

Обновленная версия трекера привычек

## О проекте

Habit Tracker помогает отслеживать личные привычки, вести дневник выполнения и получать базовую статистику.

- `backend` — NestJS API, авторизация, управление пользователями, привычками и логами.
- `frontend` — React + TypeScript приложение, интерфейс для регистрации, управления привычками и записи логов.

## Основные функции

- регистрация и вход пользователя
- создание, редактирование и удаление привычек
- запись и просмотр логов привычек
- хранение пользовательских данных на сервере
- адаптивный интерфейс для десктопа и мобильных устройств

## Как запустить

### 1. Установить зависимости

```bash
# В корне репозитория
cd frontend
npm install

cd ../backend
npm install
```

### 2. Запустить бэкенд

```bash
cd backend
npm run start:dev
```

Бэкенд по умолчанию запускается на `http://localhost:3000`.

### 3. Запустить фронтенд

```bash
cd frontend
npm run dev
```

Фронтенд открывается в браузере на `http://localhost:5173`.

## Примечания

- Убедитесь, что бэкенд запущен перед фронтендом.
- Дополнительные команды и настройки доступны в `frontend/README.md` и `backend/README.md`.

## Структура

- `frontend/` — клиентское приложение на React, Vite и Redux Toolkit.
- `backend/` — серверное приложение на NestJS с Prisma и PostgreSQL.
